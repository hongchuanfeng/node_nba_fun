public/demo.html

静态页面可以正常访问了

Static HTML pages served straight from the public directory.

这是什么 / What is this

这是一个放在 web/public/ 目录下的独立 HTML 文件，由 Next.js 的静态资源服务直接输出， 不参与 React 渲染，也不需要任何构建步骤。

This is a standalone HTML file inside web/public/. It is served as a static asset by Next.js — no React rendering and no build step involved.

访问方式 / How to reach it

  • /demo.html — public 根目录下的文件
  • /tools/scoreboard.html — public 子目录同样可以直接访问
  • 这些路径不会再做语言前缀重定向，中英文页面请自行在 HTML 内处理。

注意事项 / Notes

  • 文件名建议带扩展名（.html），中间件会自动放行静态资源。
  • public 目录下的文件由 publicPath 提供，部署时需要一并上传。
  • 如需进入站点导航，请使用 /zh 或 /en。
